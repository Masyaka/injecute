**Node.js 22.12 or newer.** The minimum Node.js version is now 22.12, the first 22.x release where `require()` loads ES modules without a flag, so CommonJS code can `require('injecute')`. ES module imports worked on older 22.x releases, but `require()` didn't.

Before → after: Node.js ≥ 22 → Node.js ≥ 22.12. See [Module format: ESM only](https://masyaka.github.io/injecute/migration/0.x-to-1.0#module-format-esm-only).
