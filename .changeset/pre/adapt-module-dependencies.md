**Docs: adapting a module's dependencies.** A new section in [Containers, forks and modules](https://masyaka.github.io/injecute/guide/containers#adapting-a-module-s-dependencies) shows how to apply a module whose dependencies the host has under other keys or in another shape: register adapters (`addAlias()`, or a factory that derives the value) in a namespace before `extend()`. The Agent Skill follows the same advice.
