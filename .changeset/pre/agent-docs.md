**Docs and an Agent Skill in the package.** The package now contains its documentation as Markdown (`llms.txt` and `lib/docs/`: guides, concepts, error codes, the migration guide) and an Agent Skill (`skills/injecute`), so coding agents read the docs of the installed version. See [Using injecute with AI agents](https://masyaka.github.io/injecute/guide/ai-agents).
